# NamiFAX LLM Wiki - 스키마(운영 규칙)

Andrej Karpathy 의 "LLM Wiki" 패턴(2026-04-04 gist)을 이 프로젝트에 맞춘 것이다. 지식은 질문할 때마다 원문에서 다시 찾지 않고
**한 번 정리해서 위키에 쌓고 계속 최신으로 유지**한다. 위키는 LLM 이 쓰고 유지하며, 사람은 자료를 고르고 질문하고 검토한다.

## 3층 구조
1. **원본 자료(raw, 불변)**: 수정하지 않는다. 이 저장소에서는 아래 두 가지다.
   - 지금 저장소에 있는 문서와 **코드**(`src/`, `tests/`, `deploy/`, `docs/*.md`). 코드가 최종 진실이다.
   - 삭제된 문서와 소스는 git 에서 읽는다(복사해 두지 않는다): `git show <커밋>:<경로>`
     | 대상 | 커밋 |
     |---|---|
     | ARCHITECTURE.md, AGENTS.md, 감사·결함 보고서(`docs/numfax-defects*`, `docs/LEGACY_DIVERGENCE_AUDIT_REPORT.md`) | `01f2f64` |
     | `dev/` (골든 마스터, specs 명세, prompts) | `72a7324` |
     | `legacy/` (원본 AvantFAX PHP 소스) | `9408385` |
2. **위키(이 폴더, LLM 소유)**: `sources/`(원본 문서별 요약), `topics/`(주제별 종합), `index.md`, `log.md`.
3. **스키마(이 파일)**: 규칙. 사람과 LLM 이 함께 고친다.

## 페이지 종류와 신뢰도
| 폴더 | 내용 | 신뢰도 표시 |
|---|---|---|
| `sources/` | 원본 문서 하나(또는 한 묶음)의 요약. **문서가 주장하는 것**을 옮긴 것이지 사실 확인이 아니다 | `verified: false` |
| `topics/` | 주제별 종합. 현재 **코드와 대조해** 쓴다 | 주장마다 `[코드]` / `[문서]` / `[추정]` 표시 |

- `[코드]`: 이 세션에서 코드·시험을 직접 읽거나 실행해 확인했다. 근거 경로를 `src/...` 로 적는다.
- `[문서]`: 문서에만 있고 코드로 확인하지 못했다. 근거 문서 페이지를 링크한다.
- `[추정]`: 확인되지 않은 추측. 가능하면 쓰지 않는다. 쓰면 이유를 적는다.
- 문서와 코드가 다르면 **코드를 따르고**, 차이를 `> 모순:` 인용 블록으로 남긴다(숨기지 않는다).

## 쓰기 규칙
- 한국어(존댓말 아님, 위키 문체: 간결한 평서문). 코드·경로·명령은 백틱.
- 파일 이름은 영문 소문자-하이픈. **이름이 폴더와 무관하게 유일**해야 한다(옵시디언 링크 `[[이름]]`).
- 모든 페이지는 frontmatter 를 가진다:
  ```
  ---
  title: 한국어 제목
  type: source | topic
  updated: 2026-10-02
  sources: [raw 경로나 [[페이지]] 목록]      # topics 는 근거로 읽은 코드 경로도 포함
  verified: true | false
  ---
  ```
- 링크는 `[[페이지-이름]]`. 존재하지 않는 페이지로 링크하지 않는다(필요하면 `index.md` 의 "만들 페이지" 에 적는다).
- 수치(시험 개수, 파일 수 등)는 **측정한 날짜와 방법**을 같이 적는다. 오래되면 거짓이 되므로 되도록 쓰지 않는다.
- 비밀번호·키·토큰 등 비밀 값은 쓰지 않는다.

## 작업 절차
- **Ingest(자료 추가)**: 원본을 읽는다 → `sources/<이름>.md` 요약을 만든다 → 영향받는 `topics/` 를 고친다 → `index.md` 갱신 → `log.md` 에 한 줄 추가.
- **Query(질문)**: `index.md` 를 먼저 읽고 관련 페이지로 간다. 가치 있는 답은 `topics/` 에 새 페이지로 되돌려 쌓는다.
- **Lint(점검)**: 모순, 낡은 주장, 고아 페이지(들어오는 링크 없음), 링크 끊김, 코드와 다른 `[코드]` 표시를 찾아 고친다. 결과를 `log.md` 에 남긴다.

## 로그 형식
`log.md` 는 추가만 한다. 항목은 `## [YYYY-MM-DD] 종류 | 제목` 으로 시작한다(종류: ingest, topic, query, lint, schema).
`grep "^## \[" log.md | tail -5` 로 최근 항목을 본다.

## 모델 분담(비용과 위험 관리)
- **하이쿠**: `sources/` 요약, 템플릿 채우기, 색인·링크 점검처럼 판단 부담이 작은 반복 작업. 결과는 `verified: false`.
- **소넷 이상**: 스키마, `topics/` 종합(코드 대조), 모순 판단, 상태를 단정하는 페이지.
- 위키는 한 번 틀리면 그 위에 쌓이므로 `topics/` 는 반드시 코드와 대조한다.
