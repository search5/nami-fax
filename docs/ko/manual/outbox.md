# 보낸 팩스함

**보낸 팩스함**(접근 키 `o`)은 현재 전송 대기열에 있는 작업을 보여 줍니다. 메뉴 옆의 숫자 배지는 진행 중인 작업 수입니다. 화면은 60초마다 자동으로 새로 고쳐집니다.

!!! note "보이는 작업"
    최고 관리자는 모든 작업을 봅니다. 그 밖의 계정은 본인이 보낸 작업(그리고 본인 대신 메일로 보낸 작업)만 봅니다.

화면 위쪽의 안내문대로, 이 화면에는 대기 중이거나 진행 중인 팩스만 표시됩니다. 전송이 완료되면 목록에서 사라지며, 완료된 기록은 [보관함](archive.md)에서 찾습니다. 작업이 하나도 없으면 "대기 중인 작업 없음" 안내와 **팩스 보내기** 버튼이 표시됩니다. [팩스 보내기](send-fax.md)에서 팩스를 등록한 직후에는 이 화면 위쪽에 "팩스를 전송 대기열에 넣었습니다. (작업 번호)"가 표시됩니다.

## 진행 중인 작업

"N건의 작업 진행 중" 배지 아래의 표에 작업이 한 줄씩 표시됩니다.

| 열 | 내용 |
|---|---|
| 작업 ID | HylaFAX 작업 번호 |
| 우선순위 | 작업 우선순위 |
| 사용자 | 작업을 등록한 사용자 |
| 회사 | 수신 번호가 주소록에 있으면 회사명, 없으면 수신 번호 |
| 페이지 수 | 전송할 페이지 수 |
| 시도 횟수 | 지금까지 다이얼한 횟수 |
| 전송 예정 | 예약된 전송 시각(예약이 없으면 비어 있음) |
| 상태 | HylaFAX가 알려 주는 작업 상태 문구(밑줄은 공백으로 표시) |
| 작업 | **수정**, **삭제** |

상태 문구는 HylaFAX가 보고하는 내용을 그대로 보여 줍니다. 서버가 어떤 문구를 쓰는지는 이 매뉴얼에서 다루지 않습니다.

## 작업 수정

**수정**을 누르면 **팩스 작업 수정** 화면이 열립니다. 바꾸고 싶은 항목만 입력하고 **저장**을 누르면 작업이 수정되고 보낸 팩스함으로 돌아갑니다. 비워 두거나 고르지 않은 항목은 바뀌지 않습니다.

| 항목 | 설명 |
|---|---|
| 새 수신처 | 수신 팩스 번호를 바꿉니다. |
| 우선순위 | 비워 두면(첫 번째 항목) 그대로 둡니다. |
| 모뎀 / 장치 | 다른 회선을 지정합니다. |
| 시도 횟수 | 최대 시도 횟수(숫자). |
| 만료 시간 | "지금 +" 숫자와 단위(**분**, **시간**, **일**). 지금부터 그 시간이 지나면 작업이 만료됩니다. |
| 전송 시각 예약 | **지금**을 체크하면 즉시 전송을 요청합니다. 오른쪽 체크 상자를 체크하고 시와 분을 고르면 그 시각으로 예약합니다. |

숫자 항목에 숫자가 아닌 값을 입력하면 "올바른 숫자를 입력하십시오."가 표시됩니다. **취소**를 누르면 변경 없이 돌아갑니다.

## 작업 삭제

**삭제**를 누르면 "작업 삭제 N?" 확인 대화상자가 나옵니다. 확인하면 작업이 대기열에서 제거되고 "Job #N successfully killed" 메시지가 표시됩니다. 제거할 수 없으면 "Failed to kill job #N", 이미 사라진 작업이면 "Job #N was not found in your queue"가 표시됩니다. 삭제한 작업은 되돌릴 수 없습니다. 세션이 만료된 경우에는 "세션이 만료되었습니다. 페이지를 새로 고친 뒤 다시 시도하십시오."가 표시되므로 화면을 새로 고친 다음 다시 누르십시오.

## 전송 실패 내역

전송에 실패한 작업은 같은 화면 아래쪽 **전송 실패 내역 — N** 표에 따로 모입니다("번호를 확인하거나 아래에서 재시도하세요."). 열은 위 표와 같으며 **전송 예정** 열만 없습니다.

- **재시도**: 같은 작업 수정 화면이 열립니다. 이 화면에서 **저장**하면 수정 내용과 함께 작업의 재전송(resubmit)을 요청합니다. 만료 시간은 처음에 3시간으로 채워져 있고, 필요하면 수신처와 다른 항목도 바꿀 수 있습니다.
- **삭제**: 실패한 작업을 목록에서 제거합니다.

## 전송 보고서와 재전송

전송이 끝난 팩스는 [보관함](archive.md)에서 다룹니다. 보관함의 각 줄 오른쪽 끝에는 배지가 있습니다(보낸 팩스는 **보냄**, 받은 팩스는 **수신일시**로 표시됩니다). 이 배지를 누르면 팩스 하나의 **전송 보고서**(회사, 날짜, 페이지 수, 팩스 번호, 첫 페이지 이미지)가 열리며, **인쇄**로 출력할 수 있습니다. 같은 문서를 다시 보내려면 보관함의 **재전송**을 사용합니다.
