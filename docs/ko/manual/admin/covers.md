# 표지

**표지 템플릿 관리**(`/admin/covers`, 사이드바 *콘텐츠 및 템플릿*)는 팩스를 보낼 때 사용자가 고를 수 있는 표지 템플릿의 목록을 관리합니다.

!!! warning "파일 업로드는 없습니다"
    이 화면은 **파일 이름을 등록**하기만 합니다. 파일을 올리거나, 올라간 파일을 찾아보거나, 파일이 있는지 확인하거나, 표지를 미리 볼 수 없습니다. 업로드는 계획만 있고 구현되어 있지 않습니다. [표지 업로드 계획](../../dev/cover-upload-plan.md)을 참고하십시오. 템플릿을 저장하는 서비스 코드는 있지만 이를 부르는 화면이 없습니다.

## 지금 이 화면으로 할 수 있는 일

**사용 가능한 표지 목록**에는 등록된 표지마다 **제목**, 괄호 안의 **파일** 이름, ID가 나옵니다. 새 데이터베이스에는 *Generic A4*(`cover.ps`), *Generic Letter*(`cover-letter.ps`), *Generic HTML*(`coverpage.html`) 세 개가 들어 있습니다.

| 작업 | 방법 |
|---|---|
| 등록 | **새 표지 템플릿**을 누르고 **제목** \*과 **파일** \*(입력 칸 예시는 `custom.ps`)을 채운 뒤 **저장**합니다. |
| 수정 | 항목의 **편집**을 누릅니다. **제목**과 **파일**을 모두 바꿀 수 있습니다. **저장**하면 새 값이 반영됩니다(*표지 템플릿이 성공적으로 업데이트되었습니다.*). |
| 삭제 | 항목을 열고 **삭제**를 누릅니다(확인 창이 뜹니다). |

- 두 항목은 필수입니다(*제목과 파일은 필수 항목입니다.*).
- 이미 등록된 파일 이름은 거절됩니다(*Cover page already exists*).
- **삭제**는 목록에서 등록만 지웁니다. 파일 자체는 건드리지 않습니다.

## 파일 놓기

업로드가 없으므로 템플릿 파일은 직접 서버에 복사해야 합니다. 표지를 붙여 팩스를 보낼 때 NamiFAX는 `AVANTFAX_INSTALLDIR`(기본 `/var/www/avantfax`) 아래 `images` 폴더에서 파일을 찾습니다. 그 폴더에 있는 이름과 똑같이 등록하십시오. 화면은 파일이 있는지 확인하지 않으며, 파일이 없으면 팩스를 보낼 때 표지가 제대로 만들어지지 않습니다.

사용자는 팩스 보내기 양식에서 표지를 고르고, 자기 계정에서 기본 표지를 지정할 수 있습니다([사용자](users.md) 화면의 **표지 선택**).

## 템플릿 형식

표지 생성기가 읽는 형식은 다음과 같습니다.

- **PostScript**(`.ps`)
- **HTML**(`.html`, `.htm`): 환경변수 `USE_HTML_COVERPAGE`가 `1` 또는 `true`일 때만 읽습니다.

템플릿에서 치환 자리표시자는 `XXXX-` 뒤에 이름을 붙인 글자입니다. 표지를 만들 때 모두 값으로 바뀌고, 모르는 이름은 빈 값이 됩니다. 생성기가 채우는 이름은 다음과 같습니다.

`from`, `from-mail-address`, `to`, `to-company`, `to-location`, `to-voice-number`, `to-fax-number`, `regarding`, `from-company`, `from-location`, `from-voice-number`, `from-fax-number`, `page-count`, `todays-date`, `comments`.

예를 들어 `XXXX-to-company`는 받는 사람의 회사가 됩니다. 새 템플릿은 NamiFAX의 `images` 폴더에 있는 `cover.ps`나 `coverpage.html`을 복사해 고치는 것이 가장 쉽습니다.

!!! note "화면에 나오는 태그 목록"
    양식 아래에는 `@TO_COMPANY@` 같은 형식의 태그를 나열한 **표지 템플릿 스튜디오: 동적 태그 레퍼런스** 카드가 나옵니다. 현재 코드의 표지 생성기는 이 표기를 읽지 **않습니다**. 위의 `XXXX-` 이름을 쓰십시오.
