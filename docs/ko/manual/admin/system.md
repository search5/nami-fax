# 시스템

이 페이지는 **시스템 기능**, **시스템 감사 로그**, **SMTP 게이트웨이**, **네트워크 프린터**를 다룹니다. 앞의 둘은 *관리자 콘솔* 또는 *최고 관리자* 플래그가 있으면 되고, 뒤의 둘은 *최고 관리자* 플래그가 필요합니다([개요](index.md) 참고).

## 시스템 기능

**시스템 기능**(`/admin/sysfunc`, `/admin/system_func`도 같은 화면)은 한 양식 안에 패널 두 개가 있습니다.

!!! danger "버튼을 누르기 전에 읽으십시오"
    화면은 재시작이나 종료가 진행 중인 모뎀 스풀링을 중단시키고 클라이언트 연결을 끊는다고 경고합니다. 모뎀 대기열에 전송이 남아 있지 않은지 먼저 확인하십시오.

### 데몬 서비스 제어

서버에서 이름으로 찾은 프로세스 세 개가 돌고 있는지 보여 줍니다. HylaFAX의 **faxq daemon**, **hfaxd daemon**과 NamiFAX 웹 프로세스인 **web worker**(프로세스 ID 포함)입니다. 각각 `실행 중 (pid n)`, `실행 중 아님`, 확인할 수 없을 때 `알 수 없음`으로 나옵니다.

| 버튼 | 실제로 하는 일 |
|---|---|
| **서비스 재시작** | 환경변수 `NAMIFAX_REBOOT_CMD`의 명령을 실행합니다. 기본값은 `sudo /sbin/reboot`입니다. 서비스만이 아니라 **서버 전체**가 다시 시작됩니다. 확인 창은 뜨지 않습니다. |
| **서비스 종료** | `NAMIFAX_SHUTDOWN_CMD`를 실행합니다. 기본값은 `sudo /sbin/halt`입니다. **서버 전체**가 멈춥니다. 먼저 확인 창이 뜹니다. |

두 버튼 모두 웹 서비스를 실행하는 사용자가 비밀번호 입력 없이 `sudo`를 쓸 수 있어야 합니다(예: `sudoers` 규칙). 그렇지 않다면 두 변수를 환경에 맞는 명령으로 바꾸십시오. 화면은 명령이 시작되는 즉시 *시스템을 다시 시작하는 중입니다. 잠시 기다려 주세요...* 또는 *시스템을 종료하는 중입니다. 잠시 기다려 주세요...*를 보여 주며 결과를 기다리지 않습니다. 명령을 시작조차 할 수 없으면 *명령을 실행할 수 없습니다*와 이유가 나옵니다.

### 데이터베이스 및 보관함 백업

| 버튼 | 결과 |
|---|---|
| **보관함 다운로드** | 받은 팩스 보관 폴더(`AVANTFAX_ARCHIVE`, 기본 `<HYLASPOOL>/archive`)와 보낸 팩스 폴더(`AVANTFAX_ARCHIVE_SENT`, 없으면 `ARCHIVE_SENT`, 기본 `<HYLASPOOL>/sent`) 중 있는 것을 담은 gzip 압축 tar 파일 `avantfax-archive-YYYYMMDD.tar.gz`입니다. 둘 다 없으면 *내려받을 팩스 보관 폴더가 없습니다.*가 나옵니다. |
| **데이터베이스 다운로드** | gzip 압축 SQL 덤프 `avantfax-schema-YYYYMMDD.sql.gz`입니다. SQLite는 NamiFAX가 직접 덤프하고, MySQL/MariaDB는 서버에 `mysqldump`, PostgreSQL은 `pg_dump`가 있어야 합니다. 실패하면 *데이터베이스 덤프를 만들 수 없습니다*가 나옵니다. |

보관함은 클 수 있으며, 다운로드 파일은 서버에서 먼저 만든 뒤 내려보냅니다. 클라우드 저장소를 쓴다면 [스토리지와 스케줄러](storage-scheduler.md)도 보십시오.

!!! note "고정된 예시 글자"
    *Archive Storage: 12.4 GB in 1,420 files*, *Database Size: 18.2 MB*, *Last Snapshot: Today, 04:00 AM* 세 줄과 *HylaFAX 엔진 가동 중* 표시는 고정된 글자입니다. 실제로 측정한 값이 아니며, 스냅샷이 자동으로 만들어지지도 않습니다.

## 시스템 로그

메뉴의 **시스템 감사 로그**(`/admin/syslog`, `/admin/system_logs`도 같은 화면)는 화면 제목이 **시스템 로그**입니다. NamiFAX가 기록한 이벤트를 보여 줍니다. 로그인과 로그인 실패(비밀번호는 마지막 세 글자만 남기고 가려집니다), 비밀번호 초기화, 계정 잠금 해제, 수신·알림·`dynconf` 훅, 스케줄러 실행, 클라우드 업로드 실패가 여기에 남습니다. 표에는 **날짜**와 **로그 내용**이 최신순으로 한 쪽에 100줄씩 나오고, **이전** / **다음**과 *페이지 n / m*으로 넘깁니다.

- 페이지를 처음 열면 오늘의 이벤트가 나옵니다.
- **키워드**: 로그 내용에 들어 있는 글자이며 대소문자를 구분하지 않습니다.
- **날짜**: DD / MM / YYYY 드롭다운 세 개입니다. 날짜 조건에는 연도가 필요합니다. 연도만 고르면 그 해 전체, 연도와 월이면 그 달, 셋 다 고르면 하루입니다. 연도 없이 고른 일(日)은 무시됩니다.
- **검색**을 누릅니다. 날짜를 고르지 않고 검색하면 키워드에 맞는 모든 이벤트가 나옵니다.

## SMTP 게이트웨이 {#smtp}

**SMTP 게이트웨이**(`/admin/smtp`, *최고 관리자 전용*)는 NamiFAX가 보내는 모든 메일에 쓰는 메일 서버를 정합니다. 새 사용자의 비밀번호 메일, *비밀번호를 잊으셨습니까?* 메일, 연락처로 보내는 수신 팩스, 알림 메일이 모두 해당합니다. 저장한 설정이 없으면 `localhost` 25번 포트를 씁니다.

**서버 연결 및 보안**

| 항목 | 의미 |
|---|---|
| **SMTP 호스트 / 서버** \* | 서버 이름입니다. |
| **포트** \* | 1부터 65535까지입니다. |
| **암호화 프로토콜** | **없음 (일반)**, **STARTTLS (587)**, **SSL / TLS (465)** 중에서 고릅니다. 이름에 적힌 숫자는 안내일 뿐이고, 포트는 입력한 값을 씁니다. |
| **SMTP 인증 필요** | 켜면 다음 두 항목으로 로그인합니다. |
| **사용자 이름 / 로그인**, **비밀번호 / 앱 키** | 인증 정보입니다. 비밀번호 칸에는 저장된 비밀번호가 미리 채워져 있습니다. |

**기본 발신자 프로필 및 서명**: **발신자 이메일 주소** \*, **발신자 표시 이름**, **이메일 서명 (일반 텍스트)**.

**게이트웨이 설정 저장**을 누릅니다. SMTP 비밀번호는 암호화해서 저장하므로 `NAMIFAX_SECRET_KEY`(또는 ini의 `secret.key`)가 정해져 있어야 하며, 그렇지 않으면 비밀번호가 비어 있지 않은 설정을 저장할 때 오류가 납니다. 화면에는 설정을 마지막으로 바꾼 시각이 나옵니다.

**자가 진단 테스트**: **테스트 수신자 이메일**(내 주소가 미리 들어 있습니다)을 입력하고 **진단 이메일 전송**을 누릅니다. 저장 여부와 상관없이 지금 양식에 있는 값으로 서버에 접속(제한 시간 10초)하고, 인사를 나눈 뒤, 선택했다면 TLS를 시작하고 로그인해서 짧은 시험 메일을 보냅니다. **진단 결과** 상자에 단계마다 결과가 나오고, 실패하면 그 오류가 나옵니다.

## 네트워크 프린터

**네트워크 프린터**(`/admin/printers`, *최고 관리자 전용*)는 네트워크 프린터 목록을 관리합니다.

**네트워크 프린터 추가**의 항목은 **프린터 이름** \*, **프로토콜**(`RAW` 9100 포트 / JetDirect, `IPP`, `LPD` / LPR), **호스트 / IP** \*, **포트**(기본 9100), **큐 이름 (선택)**, **설명**입니다. **프린터 등록**을 누릅니다. **등록된 프린터** 목록에는 **이름**, **프로토콜**, **접속 주소**(`호스트:포트`), **설명**이 나오며 행마다 두 가지 작업이 있습니다.

- **테스트 출력**은 그 호스트와 포트로 TCP 연결을 열어 짧은 글자 한 줄과 용지 배출 코드를 보냅니다. 항목의 프로토콜과 상관없이 원시 소켓 시험이므로 9100 포트의 `RAW` 프린터에 맞는 시험이며, IPP나 LPD 시험이 아닙니다. 결과는 성공 또는 오류 메시지로 나옵니다.
- **삭제**(확인 창이 뜹니다)는 항목을 지웁니다.

!!! note "이 목록의 용도"
    현재 코드에서 이 목록은 이 화면에서만 쓰입니다. [팩스 회선, DID 경로, 바코드 규칙, 팩스-이메일](fax-lines.md)의 **프린터** 칸은 서버의 인쇄 명령에 넘기는 자유 입력 글자(예: `lp0`)이며 이 목록을 읽지 않습니다.
