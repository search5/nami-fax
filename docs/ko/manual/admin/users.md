# 사용자

**사용자 계정 관리**(`/admin/users`)는 모든 계정의 목록과, 계정을 만들거나 고치는 양식 하나로 이루어져 있습니다.

## 사용자 목록

열은 **사용자 이름**, **이름**, **이메일**, **마지막 로그인**, **마지막 IP**, **최고 관리자**(예/아니오), **관리자**(예/아니오), **작업**입니다. 사용자 이름이나 **편집**을 누르면 목록 아래 양식에 그 계정이 불려 오고, **새 사용자 생성**을 누르면 빈 양식으로 이동합니다. 한 번도 로그인하지 않은 계정은 마지막 로그인에 `Never`가 표시됩니다. 삭제된 계정은 목록에 나오지 않습니다.

사용자 이름 옆의 **잠김** 표시는 비밀번호를 너무 많이 틀렸다는 뜻입니다(아래 [잠금](#lockout) 절 참고). 그 행에는 **잠금 해제** 버튼도 나옵니다.

## 계정 만들기

**새 사용자** 양식을 채우고 **저장**을 누릅니다.

| 항목 | 규칙 |
|---|---|
| **전체 이름** \* | 필수이며 40자 이내입니다. |
| **사용자 이름** \* | 필수입니다. 영문자, 숫자, `_`, `.`만 쓸 수 있습니다. 길이는 `MAX_USERNAME_SIZE`자(기본 15) 이내이고, 이미 쓰는 이름은 안 됩니다. |
| **비밀번호** | 선택입니다. `MAX_PASSWD_SIZE`자(기본 15) 이내입니다. 비워 두면 무작위 비밀번호가 만들어져 [SMTP 게이트웨이](system.md)로 새 사용자에게 메일로 발송됩니다. |
| **이메일 주소** \* | 필수이며 올바른 주소여야 합니다. `MAX_EMAIL_SIZE`자(기본 99) 이내이고, 다른 계정이 쓰는 주소는 안 됩니다. |
| **비밀번호 만료 주기** | **안 함**, **3개월마다**, **6개월마다** 중에서 고릅니다. |
| **언어** | 사용자의 화면 언어입니다. |
| **비밀번호 재사용 허용** | 켜면 사용자가 이전에 쓴 비밀번호를 다시 고를 수 있습니다. |

비밀번호를 어떻게 주었든, 새 계정은 첫 로그인 때 자기 비밀번호를 새로 정해야 합니다(로그인 뒤에 *비밀번호 만료* 화면이 나옵니다).

나머지 항목은 사용자의 개인 기본값입니다. **회사**(My Company), **위치**, **음성 전화번호**, **팩스 번호**, **TSI ID**, **표지 선택**(등록된 [표지](covers.md) 중에서), **새 팩스 알림음**(알림음 파일이 설치되어 있을 때만 나옵니다), **받은 팩스함 쪽당 개수**, **보관함 쪽당 개수**(10, 15, 20, 25, 30, 50, 100 중에서)입니다. 회사, 위치, 번호, TSI는 환경변수 `FROM_COMPANY`, `FROM_LOCATION`, `FROM_VOICENUMBER`, `FROM_FAXNUMBER`, `DEFAULT_TSI_ID`가 있으면 그 값으로 시작합니다.

## 권한

**권한 및 기능** 아래의 체크 상자입니다.

| 체크 상자 | 의미 |
|---|---|
| **관리자 콘솔** | 관리 화면을 열 수 있습니다([개요](index.md) 참고). |
| **최고 관리자 권한** | 관리 화면을 열 수 있고 모든 회선과 카테고리의 팩스를 다룹니다. SMTP 게이트웨이, 네트워크 프린터, 스토리지 및 클라우드, SAML에는 이 권한이 필요합니다. |
| **팩스 삭제 권한** | 팩스를 삭제할 수 있습니다. 최고 관리자는 이 권한 없이도 삭제할 수 있습니다. |
| **모든 모뎀 발신 권한** | 팩스 보내기의 *회선* 목록에 *Any Available Line (Auto)* 항목이 나옵니다. |

## 일반 사용자가 보는 팩스

최고 관리자 권한이 없는 계정은 양식 아래쪽에서 체크한 항목에 속한 팩스와 자기가 보낸 팩스를 봅니다.

- **팩스 회선**: 사용자가 쓸 수 있는 모뎀입니다. DID 라우팅을 끈 상태에서는 수신 팩스를 회선 기준으로 가립니다.
- **DID 라우팅**: `ENABLE_DID_ROUTING`을 켰을 때만 나옵니다. **모두 받기**(Catch All) 항목이 들어 있습니다. DID 라우팅을 켠 상태에서는 수신 팩스를 회선 대신 이 경로 기준으로 가립니다.
- **카테고리**: 사용자가 볼 수 있는 팩스 카테고리입니다.

체크할 대상이 아직 없으면 양식에 링크가 대신 나옵니다(예: *먼저 모뎀을 만들어야 합니다*). 이 선택을 바꾸면 바로 적용됩니다.

## 계정 고치기

계정을 불러와 양식을 고칩니다. **비밀번호**를 비워 두면 현재 비밀번호를 유지합니다. 저장하면 *사용자 정보를 저장했습니다*가 나오고 계정이 다시 불려 옵니다.

- 비밀번호를 입력하면 `MIN_PASSWD_SIZE`자(기본 8) 이상, `MAX_PASSWD_SIZE`자(기본 15) 이하여야 합니다. **비밀번호 재사용 허용**을 켜지 않았다면 그 계정이 이전에 쓴 비밀번호는 거절됩니다.
- **비밀번호 만료 주기**를 바꾸면 다음 만료일이 오늘부터 3개월 또는 6개월 뒤로 정해집니다. 만료일이 지나면 다음 로그인 때 새 비밀번호를 정해야 합니다. 비밀번호가 초기화된 계정(관리자가 비활성화한 경우, *비밀번호를 잊으셨습니까?*를 쓴 경우)도 같습니다.
- **계정 사용**(수정할 때만 나옵니다)을 끄면 계정이 비활성화되어 로그인할 수 없습니다(*Account is disabled*). 다시 켠 뒤 첫 로그인 때는 새 비밀번호를 정해야 합니다.
- 사용자 이름은 바꿀 수 있으며, 옛 이름은 HylaFAX 사용자 목록에서 지워집니다.

!!! note "비밀번호 규칙 요약"
    최소·최대 길이는 `MIN_PASSWD_SIZE`, `MAX_PASSWD_SIZE`로 정하며 기본값은 8과 15입니다. 길이 검사는 비밀번호를 바꿀 때 적용됩니다. 새 계정 양식은 관리자가 직접 정하고 싶을 때만 비밀번호를 입력하면 됩니다.

## 계정 삭제

수정 양식 맨 아래의 **사용자 삭제**를 누르면 확인 화면(*다음 사용자를 삭제하시겠습니까: …*)이 나옵니다. 자신의 계정(*자신의 계정은 삭제할 수 없습니다.*)과 마지막 최고 관리자(*마지막 슈퍼유저는 삭제할 수 없습니다.*)는 삭제할 수 없습니다.

삭제한 계정은 삭제됨으로 표시되어 목록에서 사라집니다. 그 사용자 이름과 이메일 주소는 새 계정이 쓸 수 있게 되고, 저장된 비밀번호 이력은 지워집니다.

## 잠금 {#lockout}

비밀번호를 `NAMIFAX_LOGIN_MAX_FAILURES`번(기본 5) 틀린 계정은 잠깁니다. 이 잠금은 시간이 지나도 풀리지 않습니다. 풀려면 사용자 목록에서 **잠금 해제**를 누르거나(시스템 로그에 기록됩니다) 서버에서 `namifax unlock-user <사용자이름>`을 실행합니다. 자세한 내용은 [인증](authentication.md)을 보십시오.

## 2단계 인증(2FA) 초기화

사용자는 자기 설정에서 2FA를 직접 켜고 끕니다. 관리 화면에는 이를 위한 버튼이 없습니다. 인증 앱과 복구 코드를 모두 잃은 사용자가 있으면 서버에서 다음을 실행합니다.

```
namifax reset-2fa <사용자이름>
```

그 사용자의 2FA 등록이 지워지며, 사용자는 설정에서 다시 등록할 수 있습니다.
