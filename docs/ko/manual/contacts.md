# 연락처

**연락처**(접근 키 `c`)에는 자주 쓰는 수신처를 저장해 두는 세 가지 목록이 있습니다. 화면 위쪽의 탭으로 서로 오갈 수 있습니다.

| 탭 | 용도 |
|---|---|
| 이메일 주소록 | 팩스를 이메일로 전달할 때 쓰는 이메일 주소 |
| 주소록 | 회사와 회사별 팩스 번호 (연락처 메뉴를 처음 누르면 이 화면이 열립니다) |
| 배포 그룹 | 여러 팩스 번호를 묶어 한꺼번에 보내기 위한 그룹 |

!!! note "연락처 전체 표시"
    관리자가 연락처 전체 표시를 끈 서버에서는, 팩스 보내기 등의 선택 창에서 두 글자 이상 입력해야 연락처 목록이 나타납니다.

## 주소록 (회사와 팩스 번호)

주소록은 **회사** 단위로 관리하며, 한 회사에 팩스 번호를 여러 개 등록할 수 있습니다.

### 목록과 검색

- **검색** 칸에 회사 이름이나 팩스 번호 일부를 입력하면 입력하는 즉시 표가 걸러집니다. **검색** 버튼으로 서버에서 다시 검색할 수도 있습니다.
- 표에는 **회사명 / 수신자**, **팩스 번호**(등록된 번호 전부), **이메일**, **작업**이 표시되며 오른쪽 위에 "N 개 업체"가 표시됩니다.
- 각 줄의 **팩스 보내기**는 [팩스 보내기](send-fax.md) 화면을 엽니다. **편집**은 회사 편집 화면을 엽니다.
- 등록된 회사가 없으면 "등록된 연락처가 없습니다"와 **첫 번째 연락처 추가** 버튼이 나옵니다.

### 회사 추가와 편집

**+ 새 회사 추가**를 누르면 **새 회사 추가** 화면이 열립니다.

1. **회사명** *을 입력합니다.
2. **첫 번째 팩스 번호** 구역의 **팩스 번호** *를 입력합니다. 올바른 팩스 번호여야 하며, 그렇지 않으면 "올바른 팩스 번호를 입력하십시오"가 표시됩니다.
3. 필요하면 번호별로 **설명**, **카테고리**, **담당자**, **위치**, **전화번호**, **상세 주소**, **우편번호**, **도시**를 입력합니다.
4. **저장**을 누릅니다. "주소록 항목을 저장했습니다."가 표시됩니다.

기존 회사는 목록에서 **편집**(또는 회사명)을 눌러 엽니다. **회사 정보 편집** 화면에서 다음을 할 수 있습니다.

- 회사명을 바꾸거나 등록된 번호별 정보를 고칩니다.
- 번호를 없애려면 해당 구역의 **팩스 번호** 칸을 비우고 저장합니다("번호를 지우면 삭제됩니다.").
- **팩스 번호 추가** 구역에 번호를 입력하고 저장하면 번호가 추가됩니다.
- **삭제**는 계정에 삭제 권한이 있을 때만 표시되며, 확인 후 회사와 번호를 지웁니다. 권한이 없는데 삭제를 시도하면 "주소록 항목을 삭제할 권한이 없습니다."가 표시됩니다.

회사 이름을 비웠거나 저장하지 못하면 화면 위쪽에 이유가 표시됩니다. **연락처 목록으로 돌아가기**로 목록에 돌아갑니다.

### vCard(.vcf)로 가져오기

**새 회사 추가** 화면 위쪽(새 회사를 추가할 때만 표시)에 **연락처 파일(vCard) 올리기** 영역이 있습니다.

1. 필요하면 가져올 연락처에 붙일 **카테고리**를 고릅니다.
2. `.vcf` 파일을 고르고 **올리기**를 누릅니다.
3. 결과 화면에 "Successfully uploaded N contacts"가 표시됩니다.

가져오기 규칙은 다음과 같습니다.

- 카드의 팩스 번호(FAX) 줄마다 회사가 하나 만들어지고 그 번호가 등록됩니다. 회사 이름은 카드의 조직(ORG) 값을 쓰고, 조직이 없으면 사람 이름(FN)을 씁니다. 카드의 이름은 번호의 **담당자**로, 고른 카테고리는 번호의 **카테고리**로 저장됩니다.
- 카드의 이메일 줄은 이메일 주소록에 추가되며 위의 개수에는 포함되지 않습니다.
- vCard 형식이 아닌 파일은 "vCard file problem: this does not look like a vCard (.vcf) file" 오류가 표시되며, 파일 크기는 팩스 첨부와 같은 제한(기본 10 MB)을 따릅니다.

## 이메일 주소록

- **이메일 주소록** 탭에서 **검색** 칸에 이름이나 주소를 입력하면 목록이 걸러집니다.
- 표에는 **담당자명**, **소속 회사**, **이메일 주소**가 표시되고 줄마다 **편집**이 있습니다. 목록이 비어 있으면 "+ 새 연락처"를 눌러 등록하라는 안내가 나옵니다.
- **+ 새 연락처** 또는 **편집**을 누르면 **담당자명** *과 **이메일 주소** *를 입력하는 화면이 열리고 **저장**으로 저장합니다("연락처를 저장했습니다.").
- **삭제**는 최고 관리자 계정에만 표시됩니다. 다른 계정이 삭제하려 하면 "연락처를 삭제할 권한이 없습니다."가 표시됩니다.
- 새 연락처 화면 위쪽의 **연락처 파일(vCard) 올리기**로 vCard를 가져오면, 이름(FN)이 있는 카드의 이메일 주소가 모두 이메일 주소록에 추가되고 "Successfully uploaded N contacts"가 표시됩니다.
- 받은 팩스를 이메일로 보내면([받은 팩스함](inbox.md) 참고) 처음 쓴 수신 주소가 자동으로 여기에 등록됩니다.

## 배포 그룹

배포 그룹은 주소록에 있는 팩스 번호를 묶어 둔 목록입니다. 팩스 보내기에서 그룹을 고르면 그룹의 모든 번호가 수신처에 한꺼번에 들어갑니다.

### 그룹 만들기

1. **배포 그룹** 탭에서 **+ 그룹 생성**을 누르거나, 오른쪽 **새 배포 그룹 생성** 영역을 사용합니다.
2. **그룹명** *을 입력하고 **저장**(또는 **그룹 생성**)을 누릅니다.
3. 만들어진 그룹의 화면으로 이동합니다.

### 구성원 관리

- 왼쪽 **저장된 배포 그룹** 목록에서 그룹을 고르면 오른쪽에 구성원이 "회사 - 팩스 번호" 형태로 표시됩니다. 목록 위의 **검색** 칸으로 그룹을 걸러 볼 수 있고, 각 그룹에는 그룹 ID와 구성원 수가 표시됩니다.
- **구성원 추가**를 누르면 **그룹에 연락처 추가** 화면이 열립니다. **검색** 칸에 입력해 회사를 찾고, 목록(여러 개 선택 가능)에서 팩스 번호를 골라 **추가**를 누르면 "변경 사항을 저장했습니다"가 표시됩니다. **뒤로**를 눌러 그룹 화면으로 돌아옵니다.
- 구성원을 빼려면 체크 상자를 체크하고 **선택 항목 제거**를 누릅니다.
- 이름을 바꾸려면 **그룹명**을 고치고 **이름 저장**을 누릅니다.
- **삭제**는 확인("이 배포 그룹을 삭제하시겠습니까?") 후 그룹을 삭제합니다. 그룹을 삭제해도 주소록의 회사와 번호는 그대로 남습니다.

주소록에서 번호를 지우면 그 번호는 그룹의 구성원 목록에서도 표시되지 않습니다.

## 선택 창(피커)

팩스 보내기와 이메일 전달 화면에는 연락처를 골라 입력 칸에 넣어 주는 팝업 창이 있습니다. 브라우저가 팝업을 차단하지 않도록 허용하십시오.

| 위치 | 링크 | 창 제목 | 넣어지는 값 |
|---|---|---|---|
| [팩스 보내기](send-fax.md) | 연락처에서 선택 | 팩스 연락처 | "회사 - 번호" 목록에서 고른 팩스 번호(세미콜론으로 구분). 하나만 고르면 담당자·회사·주소 등 입력 칸도 채워집니다. |
| [팩스 보내기](send-fax.md) | 배포 그룹 선택 | 배포 그룹 | 고른 그룹에 속한 모든 팩스 번호(세미콜론으로 구분) |
| 이메일로 팩스 전송 ([받은 팩스함](inbox.md)) | 연락처에서 선택 | 이메일 연락처 | 고른 이메일 주소(쉼표로 구분) |

창에서 체크 상자를 체크하고 **추가**를 누르면 값이 원래 입력 칸 끝에 덧붙고 창이 닫힙니다. 위쪽 **검색** 칸에 입력하면 목록이 즉시 걸러지고, **닫기**를 누르면 아무것도 넣지 않고 창을 닫습니다. 항목이 없으면 "연락처가 없습니다"가 표시됩니다.
