# 시작하기

## 로그인

브라우저에서 NamiFAX 주소를 열면 **로그인** 화면이 나타납니다. 계정이 없으면 시스템 관리자에게 문의하십시오(화면에도 같은 안내가 있습니다).

### 비밀번호로 로그인

1. **사용자 이름**과 **비밀번호**를 입력합니다.
2. **로그인**을 누릅니다.

로그인에 성공하면 [받은 팩스함](inbox.md)으로 이동합니다. 이미 로그인한 상태에서 로그인 주소를 열어도 받은 팩스함으로 이동합니다.

사용자 이름이나 비밀번호가 틀리면 "Invalid username or password"라는 메시지가 표시됩니다. 그 밖에 다음 메시지가 나올 수 있습니다.

| 메시지 | 의미 |
|---|---|
| 사용이 중지된 계정입니다 | 관리자가 계정을 사용 중지했습니다. |
| 로그인 실패가 너무 많습니다. 잠시 후 다시 시도하십시오. | 로그인 실패가 반복되어 당분간 로그인이 제한되었습니다. |
| 로그인 실패가 너무 많아 이 계정이 잠겼습니다. 관리자가 잠금을 해제할 때까지 로그인할 수 없습니다. | 계정이 잠겼습니다. 관리자에게 잠금 해제를 요청하십시오. |

### 2단계 인증(TOTP) 단계

계정에서 2단계 인증을 켜 두었다면, 비밀번호가 맞은 뒤 **2단계 인증 (2FA)** 화면이 나옵니다.

1. **인증 코드** 칸에 인증 앱이 보여 주는 6자리 코드를 입력합니다. 휴대폰을 사용할 수 없을 때는 2단계 인증을 켤 때 받은 복구 코드를 입력합니다(복구 코드는 한 번만 쓸 수 있습니다).
2. **확인 및 로그인**을 누릅니다.

코드가 틀리면 "유효하지 않거나 만료된 인증 코드입니다."가 표시됩니다. 실패가 5회 쌓이면 15분 동안 잠기며, 이 동안에는 올바른 코드를 입력해도 거절됩니다("실패 횟수가 너무 많습니다. N분 뒤에 다시 시도하십시오."). 처음 화면으로 돌아가려면 **로그인으로 돌아가기**를 누릅니다.

2단계 인증을 설정하는 방법은 [계정 설정](account.md)을 참고하십시오.

### 패스키로 로그인

로그인 화면의 **또는 다음으로 계속** 아래에 있는 **패스키로 로그인 (Touch ID / 보안 키)** 버튼을 누르면, 사용자 이름과 비밀번호를 입력하지 않고 브라우저의 패스키 대화상자(Touch ID, 보안 키 등)로 로그인합니다.

- 먼저 [계정 설정](account.md)에서 패스키를 등록해 두어야 합니다.
- 브라우저가 패스키(WebAuthn)를 지원하지 않으면 지원하지 않는다는 알림이 표시됩니다.
- 패스키 로그인은 위의 2단계 인증(TOTP) 코드 입력을 거치지 않습니다.
- 패스키는 등록할 때 접속한 서버 주소(호스트 이름)와 연결됩니다. 등록할 때와 같은 주소로 접속하십시오.

### SAML 로그인

관리자가 SAML 2.0 로그인을 켜고 설정한 서버에서만 **SAML 2.0 기업 SSO (Okta / Entra ID)** 버튼이 나타납니다. 버튼을 누르면 회사의 ID 공급자 로그인 화면으로 이동하고, 인증이 끝나면 NamiFAX로 돌아옵니다. 이 방식도 2단계 인증(TOTP) 코드 입력을 거치지 않습니다.

로그인에 실패하면 로그인 화면으로 돌아와 이유가 표시됩니다. 예를 들어 "ID 공급자가 알려 준 사용자와 일치하는 계정이 없습니다."는 ID 공급자가 알려 준 사용자와 맞는 NamiFAX 계정이 없다는 뜻입니다. 이 경우 관리자에게 문의하십시오.

## 비밀번호를 잊었을 때

1. 로그인 화면의 **비밀번호를 잊으셨습니까?** 링크를 누릅니다.
2. **비밀번호 찾기** 화면에서 계정에 등록된 **이메일 주소**를 입력하고 **비밀번호 보내기**를 누릅니다.
3. 입력한 주소로 새 비밀번호가 담긴 메일이 발송됩니다. 그 비밀번호로 로그인한 뒤 [계정 설정](account.md)에서 원하는 비밀번호로 바꾸십시오.

해당 이메일 주소의 계정이 없으면 그 사실이 화면에 표시됩니다. 메일을 보내지 못하면 "이메일을 보내지 못했습니다"가 표시되며, 이 경우 기존 비밀번호는 그대로 유지됩니다. 새 비밀번호로 로그인하면 아래의 "비밀번호 만료" 화면이 먼저 나올 수 있습니다. 취소하려면 **취소**를 누릅니다.

## 비밀번호가 만료되었을 때

비밀번호가 재설정되었거나 만료되었거나 한 번도 사용하지 않은 계정은, 비밀번호가 맞더라도 로그인이 끝나지 않고 **비밀번호 만료** 화면으로 이동합니다("필수 조치 사항"). 이 화면에서 새 비밀번호를 정해야 로그인이 완료됩니다(2단계 인증이 켜져 있다면 그 다음에 코드 입력 단계가 이어집니다).

1. **기존 비밀번호**에 현재 비밀번호를 입력합니다.
2. **새 비밀번호**와 **새 비밀번호 확인**에 같은 새 비밀번호를 입력합니다.
3. **비밀번호 변경**을 누릅니다.

세 칸이 모두 필요하고 새 비밀번호 두 칸이 같아야 합니다. 비밀번호 길이는 기본 설정으로 8자 이상 15자 이하이며(관리자가 바꿀 수 있습니다), 예전에 쓴 비밀번호는 계정 설정에 따라 다시 쓸 수 없습니다. 조건에 맞지 않으면 이유가 화면에 표시됩니다.

## 언어 선택

로그인 화면에는 언어 선택 항목이 없습니다. 로그인한 뒤 **환경설정**의 **표시 언어**에서 언어를 고르고 **설정 업데이트**를 누르면 화면 언어가 바뀝니다. 선택한 언어는 계정에 저장되고, 이 브라우저에도 기억되어(쿠키) 다음번 로그인 화면에도 적용됩니다. 한국어를 포함해 여러 언어를 고를 수 있습니다. 자세한 내용은 [계정 설정](account.md)을 참고하십시오.

!!! tip "주소로 언어 바꾸기"
    화면 주소 끝에 `?lang=ko`처럼 붙여 열면 그 요청은 해당 언어로 표시됩니다(예: `/login?lang=ko`).

## 로그아웃

화면 오른쪽 위 사용자 이름 아래의 **로그아웃**을 누르면(접근 키 `l`) 바로 로그아웃되고 로그인 화면으로 이동합니다. 주소창에서 로그아웃 주소(`/logout`)를 직접 열면 "로그아웃하시겠습니까?" 확인 화면이 나오며, **로그아웃**을 눌러야 실제로 로그아웃됩니다. **취소**를 누르면 받은 팩스함으로 돌아갑니다.
