# 팩스 보내기

**팩스 보내기**(접근 키 `s`) 화면에서 문서를 팩스로 보냅니다. 화면 위쪽에는 **주소록**과 **배포 그룹** 바로가기 버튼이 있습니다. 양식은 네 구역으로 나뉩니다.

## 1. 수신처 및 수신자 정보

| 항목 | 설명 |
|---|---|
| 수신 팩스 번호 * | 필수 항목입니다. 여러 수신처에 한꺼번에 보내려면 번호를 세미콜론(;)으로 구분합니다(예: `+82-2-555-0199`). |
| 수신자명 | 선택 사항. 표지에 인쇄되며, 번호가 하나일 때는 수신처 이름으로도 함께 전달됩니다. |
| 회사 | 선택 사항. 표지에 인쇄됩니다. |
| 위치, 전화번호, 주소, 도시, 우편번호 | 선택 사항. 표지에 쓰입니다. |
| 제목 / 용건 | 선택 사항. 표지와 전송 작업에 용건으로 전달됩니다. |

### 연락처에서 수신처 고르기

수신 팩스 번호 칸 아래에 두 개의 링크가 있습니다. 둘 다 작은 팝업 창이 열리므로 브라우저에서 팝업이 차단되어 있으면 허용하십시오.

- **연락처에서 선택**: 주소록의 팩스 번호가 "회사 - 번호" 형태로 나열됩니다. 위쪽 상자에 입력하면 입력하는 즉시 목록이 걸러지고, 상자에서 Enter를 누르면 서버에서 검색합니다. 원하는 항목을 체크하고 **추가**를 누르면 번호가 수신 팩스 번호 칸 끝에 세미콜론으로 구분되어 덧붙고 창이 닫힙니다. **번호를 하나만** 고르면 그 번호에 저장된 담당자, 회사, 주소, 우편번호, 도시, 위치, 전화번호도 해당 입력 칸에 함께 채워집니다.
- **배포 그룹 선택**: 배포 그룹 목록이 나옵니다. 그룹을 체크하고 **추가**를 누르면 그 그룹에 속한 모든 팩스 번호가 수신 팩스 번호 칸에 덧붙습니다. 그룹 만들기는 [연락처](contacts.md)를 참고하십시오.

관리자가 연락처 전체 표시를 끈 서버에서는 두 글자 이상 입력해야 목록이 나타납니다.

## 2. 문서 첨부

- 파일 선택 영역을 눌러 파일을 고릅니다. 여러 파일을 고를 수 있고, 다시 눌러 더 추가할 수 있으며, 목록에서 `×`를 눌러 뺄 수 있습니다. 목록에는 파일 이름과 크기가 표시되고, 크기 제한을 넘는 파일은 빨간색으로 표시됩니다.
- **지원 형식: PDF, TIFF, PostScript, TXT**. 파일 이름이 아니라 파일 내용을 보고 판단하므로, 확장자만 바꾼 파일은 받아들여지지 않습니다. 일반 텍스트(UTF-8)는 허용됩니다.
- 파일 하나당 최대 크기는 화면에 "최대 10 MB"처럼 표시됩니다(기본 10 MB, 관리자가 바꿀 수 있습니다).
- Word나 Excel 문서는 PDF로 변환한 뒤 첨부하십시오.
- 파일 없이 표지만 보낼 수도 있습니다. 파일을 고르지 않고 표지도 포함하지 않으면 "보낼 파일을 선택하거나 표지를 요청하십시오."가 표시됩니다.

형식이 맞지 않으면 "File type is unauthorized (파일명)", 크기를 넘으면 "File size is over the limit (파일명)" 오류가 표시되고 아무것도 전송되지 않습니다.

## 3. 표지(Cover Page)

- **표지 포함**을 체크하면 아래 항목이 나타납니다. 기본으로 체크되어 있는지는 서버 설정(`SENDFAX_USE_COVERPAGE`, 기본값 켜짐)에 따릅니다.
- **표지 템플릿**: 관리자가 등록한 표지 중에서 고릅니다. 기본으로 선택되는 표지는 [계정 설정](account.md)의 **기본 표지 템플릿**이며, 지정하지 않았으면 목록의 첫 번째입니다. 등록된 표지가 없으면 "설정된 표지가 없습니다"가 표시됩니다.
- **발신 회선 선택**: 사용할 수 있는 회선이 둘 이상일 때만 표시됩니다. **사용 가능한 모든 회선 (자동)** 항목은 그 권한이 있는 계정에만 나타납니다. 허용되지 않은 회선을 지정하면 "이 회선은 사용할 수 없습니다."가 표시됩니다. 설정된 모뎀이 하나도 없으면 "설정된 모뎀이 없습니다"가 표시되고 전송할 수 없습니다. 이 항목은 표지 구역 안에 있어서, 표지 포함을 해제하면 화면에서 접힙니다.
- **표지 전달 내용**: 표지에 인쇄할 메모나 전달 내용입니다.

표지의 발신자 정보(이름, 회사, 위치, 전화번호, 팩스 번호)는 [계정 설정](account.md)에 입력한 값이 사용됩니다.

## 4. 고급 옵션

**고급 옵션**(우선순위, 재시도 횟수, 알림 설정)은 처음에 접혀 있으며 눌러서 펼칩니다.

| 항목 | 설명 |
|---|---|
| 우선순위 | 최고 관리자 계정에만 표시됩니다. 다른 계정은 기본값으로 전송됩니다. |
| 최대 재시도 횟수 | 1에서 10 사이의 숫자. "통화 중일 경우 자동으로 재시도합니다." 비워 두면 서버 기본값을 씁니다. |
| 만료 시간 | 숫자와 단위(**분**, **시간**, **일**). 입력한 시간 안에 전송되지 않으면 작업이 만료됩니다. 비워 두면 서버 기본값을 씁니다. |
| 전송 시각 예약 | 체크한 뒤 시와 분을 고르면 그 시각에 전송합니다. 체크하지 않으면 바로 전송합니다. |
| TSI ID | 최고 관리자 계정에만 표시됩니다. 일반 계정은 환경설정에 저장된 값이 쓰입니다. |
| 재시도 시 알림 | 체크하면 작업이 다시 대기열에 들어갈 때도 HylaFAX가 알림을 보내도록 요청합니다. 기본으로 체크되어 있는지는 서버 설정(`SENDFAX_REQUEUE_EMAIL`, 기본값 켜짐)에 따릅니다. |

## 보내기

양식 아래 **팩스 보내기** 버튼을 누르면 팩스가 HylaFAX 전송 대기열에 등록됩니다. **취소하고 받은 팩스함으로 이동**을 누르면 아무것도 보내지 않고 [받은 팩스함](inbox.md)으로 돌아갑니다.

등록에 성공하면 [보낸 팩스함](outbox.md)으로 이동하며 위쪽에 "팩스를 전송 대기열에 넣었습니다. (작업 번호)"라는 메시지가 표시됩니다. 이후 상태는 보낸 팩스함에서 확인하고, 전송이 끝난 팩스는 [보관함](archive.md)에서 찾을 수 있습니다.

등록하지 못하면 같은 양식 위에 오류가 표시되고 입력한 내용은 그대로 남습니다. 예를 들어 수신 팩스 번호를 비웠을 때, 허용되지 않은 파일을 골랐을 때, 서버에 HylaFAX(`sendfax` 프로그램)가 설치되어 있지 않거나 연결할 수 없을 때입니다. 마지막 경우에는 관리자에게 문의하십시오.

!!! note "받은 팩스에 회신할 때"
    [받은 팩스함](inbox.md)이나 [보관함](archive.md)에서 **회신** / **재전송**을 누르면 이 화면이 열리고, 원본 팩스가 자동으로 첨부됩니다("원본 팩스를 함께 보냅니다."). 받은 팩스의 발신 번호가 수신처에 채워집니다.
