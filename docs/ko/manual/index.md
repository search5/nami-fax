# NamiFAX 사용자 매뉴얼

이 매뉴얼은 NamiFAX를 일반 사용자로 사용하는 방법을 설명합니다. 팩스를 받고, 보내고, 찾고, 연락처를 관리하고, 본인 계정을 설정하는 화면을 다룹니다. 시스템 관리자 화면은 [관리자 매뉴얼](admin/index.md)을 참고하십시오.

!!! note "화면 구성은 계정과 서버 설정에 따라 다를 수 있습니다"
    어떤 팩스가 보이는지(회선, 카테고리), 삭제 버튼이 보이는지, 우선순위·TSI 항목이 보이는지는 계정에 부여된 권한에 따라 달라집니다. 일부 기능은 관리자가 서버 설정에서 켜야 동작합니다. 해당하는 곳마다 조건을 적어 두었습니다.

## 화면 지도

로그인하면 화면 위쪽에 다음 메뉴가 표시됩니다. 접근 키(access key)는 브라우저의 접근 키 조합(브라우저와 운영체제마다 다릅니다)과 함께 누르면 해당 화면으로 이동하는 단축키입니다.

| 메뉴 | 접근 키 | 설명 | 자세한 설명 |
|---|---|---|---|
| 받은 팩스함 | `i` | 수신한 팩스 목록. 메뉴 옆의 숫자 배지는 받은 팩스 수입니다. | [받은 팩스함](inbox.md) |
| 팩스 보내기 | `s` | 팩스 발송 양식. 오른쪽 위의 파란색 **팩스 보내기** 버튼도 같은 화면으로 이동합니다. | [팩스 보내기](send-fax.md) |
| 보낸 팩스함 | `o` | 대기 중이거나 전송 중인 작업. 숫자 배지는 진행 중인 작업 수입니다. | [보낸 팩스함](outbox.md) |
| 보관함 | `a` | 보낸 팩스와 보관한 팩스를 검색합니다. | [보관함](archive.md) |
| 연락처 | `c` | 주소록, 이메일 주소록, 배포 그룹. | [연락처](contacts.md) |

화면 오른쪽 위에는 다음 항목도 있습니다.

- **환경설정** (접근 키 `p`): 프로필, 언어, 비밀번호, 2단계 인증, 패스키. [계정 설정](account.md)을 참고하십시오.
- **로그아웃** (접근 키 `l`).
- 팩스 회선 상태 표시: 사용할 수 있는 회선이 있으면 녹색으로 "Ready" 개수가, 없으면 "Standby"가 표시됩니다.
- 관리자 계정에는 톱니바퀴 모양의 관리자 화면 링크가 추가로 보입니다. 최고 관리자 계정에는 이름 옆에 **최고 관리자** 배지가 붙습니다.

!!! tip "좁은 화면"
    화면 폭이 좁으면(휴대폰 등) 위쪽 메뉴 줄이 숨겨집니다. 이때는 주소를 직접 입력하거나 각 화면의 버튼과 링크를 사용하십시오.

## 매뉴얼 구성

1. [시작하기](getting-started.md): 로그인(비밀번호, 2단계 인증, 패스키, SAML), 비밀번호 찾기, 만료된 비밀번호, 언어, 로그아웃
2. [받은 팩스함](inbox.md): 목록, 팩스 보기, 발신자 지정, 메모, 이메일 전달, 보관과 삭제
3. [팩스 보내기](send-fax.md): 수신처, 첨부 파일, 표지, 고급 옵션, 전송 후 동작
4. [보낸 팩스함](outbox.md): 대기열, 작업 수정과 삭제, 재시도, 전송 보고서
5. [보관함](archive.md): 검색 조건, 결과, 작업
6. [연락처](contacts.md): 주소록, 이메일 주소록, 배포 그룹, vCard 가져오기, 선택 창
7. [계정 설정](account.md): 프로필, 언어, 비밀번호, 2단계 인증, 패스키

관리자용 설정은 [관리자 매뉴얼](admin/index.md)에서 다룹니다.
