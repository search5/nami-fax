# 보관함

**보관함**(접근 키 `a`)은 [받은 팩스함](inbox.md)에서 보관한 팩스와 보낸 팩스를 검색하는 화면입니다. 화면 제목은 **보관함 검색**이며, 아직 받은 팩스함에 남아 있는 팩스는 여기에 나타나지 않습니다. 계정에 허용된 범위의 팩스(본인이 보낸 팩스와 허용된 회선·카테고리의 팩스)만 검색되며, 최고 관리자는 전체를 검색합니다.

## 검색하기

화면을 처음 열면 검색 없이 **오늘 날짜**의 팩스가 나열되고, 날짜 선택 칸에도 오늘 날짜가 들어 있습니다. 필터를 비워 두면 전체 기록을 검색하며, 조건을 더하면 결과가 좁혀집니다.

| 필터 | 설명 |
|---|---|
| 업체 검색 | 회사 이름 일부를 입력하면 아래 **업체 목록**이 입력과 함께 갱신됩니다. |
| 업체 목록 | 목록에서 회사를 고르면 그 회사의 팩스만 검색합니다. |
| 팩스 ID | 팩스 번호(ID) 하나를 정확히 지정합니다. |
| 검색어 | 팩스에 달린 메모(설명)에서 찾습니다. 서버에서 OCR(`ENABLE_OCR_SUPPORT`)을 켜서 팩스 내용의 글자가 저장되어 있다면 그 글자도 함께 검색합니다. |
| 카테고리 | **모든 카테고리** 또는 계정에서 쓸 수 있는 카테고리 하나 |
| 사용자 | 최고 관리자 계정에만 표시됩니다. 특정 사용자가 보낸 팩스만 봅니다. |
| 시작 날짜 / 종료 날짜 | 각각 일, 월, 연 선택 칸으로 되어 있고 빈 칸은 "지정 안 함"입니다. |
| 구분 | **보낸 팩스와 받은 팩스 모두**, **보낸 팩스만**, **받은 팩스만** |

조건을 정한 뒤 **검색**을 누릅니다. **초기화**는 필터를 처음 상태로 되돌립니다.

### 날짜 지정 방법

- **시작 날짜**는 연도부터 지정해야 합니다. 연도만 고르면 그 해 전체, 연과 월을 고르면 그 달 전체, 일까지 고르면 그 날 하루를 찾습니다.
- **종료 날짜**를 함께 지정하면 시작 날짜부터 종료 날짜까지의 기간을 찾습니다. 종료 날짜에서 일을 비우면 그 달 끝까지, 월과 일을 비우면 그 해 끝까지로 계산합니다.
- **종료 날짜만** 지정하고 시작 연도를 비워 두면 날짜 조건은 적용되지 않습니다.
- 브라우저 검색창에서 보관함을 검색하도록 추가한 경우(검색 엔진 추가 기능)에는 날짜와 관계없이 전체 기록을 검색합니다.

!!! note "OCR 검색"
    OCR은 관리자가 서버 설정에서 켠 경우에만 동작합니다. 켜기 전에 처리된 팩스나 글자를 읽지 못한 팩스는 내용으로 검색되지 않고, 메모(설명)로만 검색됩니다.

## 결과

결과 위쪽에 "총 N건을 찾았습니다."가 표시되고, 페이지가 여러 개이면 범위(예: `1 - 25`)와 하단의 번호 링크, `‹` `›` 링크가 나타납니다. 한 페이지의 크기는 [계정 설정](account.md)의 **보관함 쪽당 팩스 수**로 정합니다. 결과가 없으면 "검색 결과가 없습니다"와 **필터 초기화** 링크가 표시됩니다.

표의 각 줄은 최신 팩스부터 다음 내용을 보여 줍니다.

| 열 | 내용 |
|---|---|
| # | 결과 순번 |
| 축소 이미지 | 첫 페이지. 줄 위에 마우스를 올리면 큰 미리보기가 나타납니다. |
| (작업 단추) | 아래 표 참고 |
| 회사 | 회사명과 번호. 받은 팩스와 같은 규칙으로 표시되며, 발신자를 지정하거나 회사 이름을 바꾸는 링크가 나올 수 있습니다([받은 팩스함](inbox.md)의 "발신자(회사) 지정" 참고). |
| 설명 | 팩스에 달린 메모 |
| 페이지 수 | 페이지 수 |
| 카테고리 | 지정된 카테고리 |
| 날짜 | 보관/전송 일시 |
| 사용자 | 최고 관리자 계정에만 표시됩니다. |
| (배지) | 보낸 팩스는 **보냄**, 받은 팩스는 **수신일시**로 표시됩니다. 누르면 **전송 보고서**가 열립니다. |

작업 단추는 다음과 같습니다.

| 단추 | 동작 |
|---|---|
| PDF | 팩스 PDF를 내려받습니다. |
| 재전송 | [팩스 보내기](send-fax.md) 화면을 열고 이 팩스를 원본으로 첨부합니다. |
| 이메일 | PDF를 이메일로 보냅니다([받은 팩스함](inbox.md)의 "이메일로 전달" 참고). 받은 팩스함에 없는 팩스이므로 카테고리와 보관 항목은 나오지 않습니다. |
| 메모 | 메모를 달거나 바꿉니다([받은 팩스함](inbox.md)의 "메모" 참고). |
| 삭제 | 삭제 권한이 있을 때만 표시됩니다. 확인 후 영구 삭제합니다. |

## 전송 보고서

줄 끝의 배지를 누르면 **전송 보고서**가 열립니다. **회사**, **날짜**, **페이지 수**, **팩스 번호**와 첫 페이지 이미지가 표시되며, **인쇄** 버튼으로 출력하고 **닫기**로 창을 닫습니다.
