# 계정 설정

오른쪽 위의 **환경설정**(접근 키 `p`)을 누르면 **사용자 환경설정** 화면이 열립니다. 위쪽 **받은 팩스함으로 돌아가기**로 언제든 돌아갈 수 있습니다. 프로필·환경·비밀번호는 한 양식이며 맨 아래 **설정 업데이트**를 눌러 한꺼번에 저장합니다. 2단계 인증과 패스키는 이 양식 아래의 별도 영역에서 따로 처리됩니다.

저장에 성공하면 "Settings updated successfully."가 표시됩니다.

## 개인 및 조직 세부 정보

| 항목 | 설명 |
|---|---|
| 전체 이름 * | 필수. 비우면 "이름을 입력하세요"가 표시됩니다. 화면 위쪽의 이름과 이메일 전달 시 보낸 사람 이름으로 쓰입니다. |
| 이메일 주소 * | 필수. 올바른 주소여야 하며 [비밀번호 찾기](getting-started.md)와 팩스 이메일 발송에 쓰입니다. |
| 회사명, 사무실 / 위치, 직통 전화번호, 직통 팩스 번호 | 보내는 팩스의 표지에 인쇄되는 발신자 정보입니다. |
| 발신 팩스 식별자 (TSI) | 최고 관리자 계정에만 표시됩니다. 전송되는 팩스 페이지 상단에 인쇄되는 헤더 식별자입니다. |
| 이메일 및 팩스 알림 서명 | 팩스를 이메일로 보낼 때 **내용** 칸에 미리 채워지는 서명입니다. |

## 포털 및 수신 기본 설정

| 항목 | 설명 |
|---|---|
| 표시 언어 | 화면 언어. 한국어, 영어, 일본어, 중국어(간체·번체), 독일어, 프랑스어 등 여러 언어 중에서 고릅니다. |
| 기본 표지 템플릿 | [팩스 보내기](send-fax.md)에서 처음 선택되는 표지. 관리자가 등록한 표지 중에서 고릅니다. |
| 페이지당 팩스 수 | [받은 팩스함](inbox.md) 한 페이지에 보이는 팩스 수 (10, 15, 20, 25, 30, 50, 100) |
| 보관함 쪽당 팩스 수 | [보관함](archive.md) 한 페이지에 보이는 팩스 수 (같은 선택지) |

언어를 바꾸면 계정에 저장되고, 이 브라우저에도 1년간 기억되어 로그인 화면에 적용됩니다.

## 비밀번호 변경

**비밀번호 변경** 영역은 비워 두면 건너뜁니다. 바꾸려면 다음 세 칸을 모두 채우고 **설정 업데이트**를 누릅니다.

1. **현재 비밀번호**
2. **새 비밀번호**
3. **새 비밀번호 확인**

현재 비밀번호가 틀리거나 새 비밀번호 두 칸이 다르면 오류가 표시되고, 비밀번호와 함께 입력한 다른 설정도 저장되지 않습니다. 비밀번호 길이는 기본 설정으로 8자 이상 15자 이하이며(관리자가 바꿀 수 있습니다), 계정 설정에 따라 이전에 쓴 비밀번호는 다시 쓸 수 없습니다. 오류 메시지는 영어로 표시될 수 있습니다.

## 2단계 인증 (TOTP)

**2단계 인증 (TOTP)** 영역의 오른쪽 위 배지가 현재 상태를 보여 줍니다(**사용 중** / **사용 안 함**). 사용하면 비밀번호로 로그인할 때 비밀번호에 더해 휴대폰 앱의 6자리 일회용 코드가 필요합니다. Google Authenticator, Authy 등 RFC 6238을 지원하는 앱을 쓸 수 있습니다.

!!! note "패스키·SAML 로그인과의 관계"
    2단계 인증 코드는 비밀번호 로그인에만 적용됩니다. 패스키나 SAML로 로그인할 때는 코드를 묻지 않습니다.

### 켜기

1. **2단계 인증 켜기 (인증 앱 설정)**를 누릅니다.
2. 설정 화면의 1단계: 인증 앱으로 QR 코드를 스캔합니다. 스캔할 수 없으면 **키**를 앱에 직접 입력합니다(**키 복사**로 복사할 수 있습니다).
3. 2단계: 앱에 표시된 6자리 코드를 입력하고 **2단계 인증 켜기**를 누릅니다. 코드가 맞지 않으면 "코드가 일치하지 않습니다. 휴대폰의 시간을 확인하고 다시 시도하십시오."가 표시됩니다.
4. 성공하면 **복구 코드를 저장하십시오** 화면에 복구 코드 8개가 표시됩니다.
5. **코드 복사**나 **파일로 내려받기**로 안전한 곳에 보관한 뒤 **완료**를 누릅니다.

복구 코드는 휴대폰을 잃어버렸을 때 쓰는 비상용이며 각 코드는 한 번만 사용할 수 있습니다. 이 화면에서만 표시되므로 반드시 보관하십시오. 내려받는 파일은 브라우저에서 만들어지며 서버에는 저장되지 않고, 서버에는 코드가 해시로만 보관됩니다. 파일에는 복구 코드만 들어 있고 인증 앱 키는 들어 있지 않습니다.

### 사용 중일 때

켜진 상태에서는 "N개의 복구 코드가 남았습니다"가 표시되며 다음 두 가지를 할 수 있습니다.

- **새 복구 코드**: 앱의 현재 코드를 입력하고 누르면 기존 복구 코드가 모두 새 코드로 바뀌어 새로 표시됩니다.
- **2단계 인증 끄기**: **비밀번호**와 **코드 또는 복구 코드**를 입력하고 누른 뒤 "내 계정의 2단계 인증을 끄시겠습니까?"에서 확인하면 꺼지고 환경설정 화면으로 돌아갑니다. 비밀번호가 틀리면 "비밀번호가 올바르지 않습니다.", 코드가 틀리면 "코드가 올바르지 않습니다."가 표시됩니다.

코드를 5번 틀리면 15분 동안 잠기며("실패 횟수가 너무 많습니다. N분 뒤에 다시 시도하십시오.") 이 동안에는 올바른 코드도 거절됩니다. 휴대폰과 복구 코드를 모두 잃었다면 시스템 관리자에게 문의하십시오.

서버에 암호화 키가 설정되어 있지 않으면 설정 화면에 오류 안내가 표시될 수 있습니다. 이 경우에도 관리자에게 문의하십시오.

## 패스키 (FIDO2)

**FIDO2 패스키 및 생체 보안 키** 영역에서는 Touch ID, Face ID, Windows Hello, YubiKey 같은 장치로 비밀번호 없이 로그인하기 위한 패스키를 관리합니다.

1. **새 패스키 등록**을 누릅니다.
2. 브라우저가 묻는 창에 이 보안 키를 알아볼 이름을 입력합니다(예: MacBook Touch ID, YubiKey).
3. 이어서 나타나는 장치/브라우저의 안내에 따라 지문, 얼굴, 보안 키 등으로 확인합니다.
4. 등록되면 목록에 장치 이름과 등록 시각이 표시됩니다.

목록의 **삭제**를 누르면 확인 후 그 패스키가 제거됩니다. 등록된 패스키가 없으면 "등록된 패스키가 없습니다."가 표시됩니다.

- 브라우저가 패스키(WebAuthn)를 지원하지 않으면 지원하지 않는다는 알림이 표시됩니다.
- 패스키는 등록할 때 접속한 서버 주소(호스트 이름)에 묶입니다. 로그인할 때도 같은 주소로 접속하십시오.
- 로그인 화면의 **패스키로 로그인 (Touch ID / 보안 키)** 버튼으로 로그인하는 방법은 [시작하기](getting-started.md)를 참고하십시오.
