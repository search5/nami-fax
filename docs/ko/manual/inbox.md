# 받은 팩스함

**받은 팩스함**(접근 키 `i`)에는 수신된 팩스가 최신순으로 표시됩니다. 계정에 허용된 회선과 카테고리의 팩스만 보입니다.

## 목록

화면 위쪽에는 팩스 수 배지("N 개의 팩스")와 **팩스 보내기** 버튼이 있고, 팩스가 있으면 그 아래에 일괄 작업 줄과 표가 나옵니다.

| 열 | 내용 |
|---|---|
| (체크 상자) | 일괄 작업 대상으로 고릅니다. |
| 미리보기 | 첫 페이지의 축소 이미지. 누르면 팩스 보기 화면이 열립니다. |
| 발신자 | 회사명(주소록에서 찾은 이름) 또는 발신 번호. 아래에 발신 번호와 메모가 함께 표시됩니다. |
| 수신일시 | 수신 날짜와 시각. 회선 이름이 있으면 그 아래에 표시됩니다. |
| 페이지 수 | 팩스 페이지 수 |
| 작업 | **보기**, **PDF**, **회신**, 그리고 `···` 메뉴 |

`···` 메뉴에는 다음 항목이 있습니다.

| 항목 | 동작 |
|---|---|
| 보관함 | 이 팩스를 받은 팩스함에서 보관함으로 옮깁니다. |
| 이메일로 팩스 전송 | 팩스를 PDF로 이메일에 첨부해 보냅니다. 아래 "이메일로 전달"을 참고하십시오. |
| 메모 추가 | 팩스에 메모를 답니다. 아래 "메모"를 참고하십시오. |
| 회전 | 팩스를 90도 회전합니다. |
| TIFF 내려받기 | 서버에서 TIFF 내려받기를 켠 경우에만 나타납니다. |
| 삭제 | 계정에 삭제 권한이 있을 때만 나타납니다. |

### 페이지 나누기와 목록 크기

- 목록 아래에 "1 - 25 (N 개의 팩스)" 같은 범위와, 페이지가 둘 이상이면 번호 링크와 `‹` `›` 이전/다음 링크가 표시됩니다.
- 한 페이지에 보이는 팩스 수는 [계정 설정](account.md)의 **페이지당 팩스 수**로 정합니다(10, 15, 20, 25, 30, 50, 100). 설정하지 않았으면 서버의 기본값을 씁니다. 주소 끝에 `?pagelimit=숫자`를 붙이면 그 요청에서만 크기를 바꿀 수 있으며 10 미만은 10으로 처리됩니다.
- 받은 팩스함에는 검색 상자나 필터가 없습니다. 조건으로 찾으려면 [보관함](archive.md)을 사용하십시오.
- 서버에서 `INBOX_LIST_MODEM`을 켠 경우에는 날짜순 대신 팩스가 회선별로 묶여 회선 이름 제목 줄과 함께 표시됩니다.

### 새 팩스 알림

받은 팩스함이 열려 있는 동안 브라우저가 30초마다 새 팩스 수를 확인합니다. 수가 바뀌면 메뉴 옆 숫자와 브라우저 탭 제목의 숫자가 바뀌고, 받은 팩스함 화면에서는 목록이 자동으로 다시 불러와집니다. 서버 설정에서 다음 기능을 켠 경우에는 새 팩스가 오면 창을 앞으로 가져오거나(`FOCUS_ON_NEW_FAX`), 브라우저 알림을 띄우고 계정에 설정된 알림음을 재생합니다(`FOCUS_ON_NEW_FAX_POPUP`, 브라우저에서 알림을 허용해야 합니다). 둘 다 기본값은 꺼짐입니다.

팩스가 하나도 없으면 "0건의 팩스" 안내와 함께 **첫 번째 팩스 보내기**, **보관함 검색** 버튼이 표시됩니다.

## 팩스 보기

목록에서 미리보기 이미지나 **보기**를 누르면 보기 화면이 열립니다. 받은 팩스함에 있는 팩스만 열 수 있으며, 이미 보관했거나 삭제한 팩스, 권한이 없는 팩스의 주소를 열면 받은 팩스함으로 돌아갑니다.

- 위쪽에 **보낸 사람**, **날짜**, **페이지 수**, FaxID, **장치**(수신 회선)가 표시됩니다.
- 왼쪽 세로 줄에는 페이지별 축소 이미지(번호 포함)가 있습니다. 축소 이미지를 누르면 그 페이지가 크게 표시됩니다. 큰 이미지를 누르면 다음 페이지로 넘어가며, 마지막 페이지에서 누르면 첫 페이지로 돌아갑니다.

단추는 다음과 같습니다.

| 단추 | 동작 |
|---|---|
| 이전 / 다음 | 목록의 이전 팩스, 다음 팩스로 이동합니다(해당 팩스가 있을 때만 표시). |
| 회전 | 팩스를 90도 회전합니다. |
| PDF | PDF를 내려받습니다(브라우저에 따라 창 안에 바로 열릴 수 있습니다). |
| TIFF | 서버에서 TIFF 내려받기를 켠 경우에만 나타납니다. |
| 회신 | 이 팩스의 발신 번호를 수신처로 채운 [팩스 보내기](send-fax.md) 화면을 엽니다. 원본 팩스가 함께 전송됩니다. |
| 이메일 | PDF를 이메일로 보냅니다. |
| 메모 | 메모를 답니다. |
| 보관함 | 보관함으로 옮기고, 다음 팩스(없으면 이전 팩스, 둘 다 없으면 받은 팩스함)로 이동합니다. |
| 삭제 | 삭제 권한이 있을 때만 나타납니다. 삭제 후 다음 팩스로 이동합니다. |
| 받은 팩스함 → | 목록으로 돌아갑니다. |

## 발신자(회사) 지정

발신자 칸은 주소록과 비교해 다음 중 하나로 표시됩니다.

| 표시 | 의미 | 할 일 |
|---|---|---|
| 회사명 링크 | 주소록에 등록된 번호입니다. 링크를 누르면 주소록의 해당 회사 편집 화면이 열립니다. | 없음 |
| 번호(또는 "알 수 없는 발신자") 링크 | 주소록에 없는 발신자입니다. | 링크를 눌러 **발신자 지정** 화면에서 이름을 지정합니다. |
| 회사 이름이 번호와 같은 링크 | 번호 자체가 회사 이름으로 등록되어 있습니다. | 링크를 눌러 **회사명 지정** 화면에서 이름을 바꿉니다. |
| 드롭다운과 **선택** 버튼 | "이 번호는 여러 회사에 등록되어 있습니다. 어느 회사입니까?" 같은 번호가 여러 회사에 등록된 경우입니다. | 맞는 회사를 고르고 **선택**을 누릅니다. |

### 발신자 지정 화면

주소록에 없는 발신자의 링크를 누르면 나타납니다. 위쪽에 발신 번호가 표시됩니다.

- **연락처 선택**: 기존 회사 목록에서 고릅니다.
- **또는 새 회사 이름을 입력하십시오**: 새 회사를 만들어 지정합니다.
- **저장**을 누르면 이 팩스가 해당 회사의 팩스가 되고 받은 팩스함으로 돌아갑니다. 둘 다 비워 두면 "회사 이름을 입력하십시오"가 표시됩니다.

### 회사명 지정 화면

번호 자체가 회사 이름으로 되어 있을 때 나타납니다.

- **회사명 검색** 칸에 새 이름을 입력하고 **저장**하면 그 회사의 이름이 바뀝니다. 입력 칸의 안내 문구는 "회사 이름을 입력해 찾으십시오..."이지만 목록을 걸러 주지는 않으며, 입력한 내용이 새 회사 이름으로 저장됩니다.
- 대신 **연락처 선택** 목록에서 기존 회사를 고르고 **저장**하면, 이 회사의 번호와 팩스가 고른 회사로 합쳐지고 이 회사는 사라집니다.
- 이름이 숫자뿐이고 서버에 화이트 페이지 주소가 설정되어 있으면 입력 칸 옆에 화이트 페이지 검색 아이콘이 표시됩니다.

## 메모

**메모 추가**(또는 보기 화면의 **메모**)를 누르면 **메모 / 설명** 상자가 열립니다. 내용을 입력하고 **저장**을 누르면 팩스의 설명으로 저장되어 받은 팩스함에서는 발신자 아래에, 보관함에서는 **설명** 열에 표시됩니다. 이 상자에는 처음에 "Reviewed and verified by operator."라는 문장이 채워져 있으므로 필요한 내용으로 바꿔서 저장하십시오. 보관함의 **검색어**로 메모 내용을 찾을 수 있습니다.

## 이메일로 전달

**이메일로 팩스 전송**(보기 화면에서는 **이메일**)을 누르면 **이메일로 팩스 전송** 화면이 열립니다.

| 항목 | 설명 |
|---|---|
| 보낸 사람 | 내 이름과 이메일 주소(환경설정에 등록한 값). 변경할 수 없습니다. |
| 수신자 * | 받는 사람의 주소. 여러 개는 쉼표 등으로 구분합니다. **연락처에서 선택**으로 이메일 주소록에서 고를 수 있습니다. |
| 참조 / 숨은 참조 | 선택 사항 |
| 제목 | 기본값은 회사명(45자까지) |
| PDF 파일 이름 | 기본값은 `fax-회사명.pdf` 형태 |
| 내용 | 환경설정의 이메일 서명이 미리 채워집니다. |
| 카테고리 | 받은 팩스함의 팩스일 때만 표시됩니다. 고르면 이 팩스에 카테고리가 지정됩니다. |
| 팩스 보관 | 받은 팩스함의 팩스일 때만 표시되며 기본으로 체크되어 있습니다. 체크한 채 보내면 메일 발송 후 보관함으로 옮겨집니다. |

**전송**을 누르면 PDF가 첨부된 메일이 발송되고 "메일을 보냈습니다"가 표시됩니다. 처음 보낸 주소는 이메일 주소록에 자동으로 추가됩니다. 주소 형식이 틀리면 "올바른 이메일 주소를 입력하십시오.", 메일 발송에 실패하면 "메일을 보내지 못했습니다"가 표시됩니다.

## 보관과 삭제

- **보관**: 팩스를 받은 팩스함에서 [보관함](archive.md)으로 옮깁니다. 팩스 자체는 지워지지 않습니다.
- **삭제**: **팩스 삭제** 확인 화면이 나오며 "이 팩스를 삭제하시겠습니까?" "이 작업은 팩스 문서 보관 파일을 영구적으로 삭제합니다."라고 안내합니다. **삭제**를 누르면 되돌릴 수 없습니다. 계정에 삭제 권한이 없으면 삭제 단추 자체가 표시되지 않습니다.

## 일괄 작업

표 위의 일괄 작업 줄에서 여러 팩스를 한 번에 처리합니다.

1. 각 줄의 체크 상자를 고르거나 **전체 선택**을 체크합니다(현재 페이지의 모든 팩스가 선택됩니다).
2. **선택 항목 보관**을 누르면 선택한 팩스가 모두 보관함으로 옮겨집니다.
3. **선택 항목 삭제**(삭제 권한이 있을 때만 표시)를 누르면 "선택한 팩스를 삭제하시겠습니까?"와 팩스 수를 보여 주는 확인 화면이 나옵니다. **삭제**를 누르면 삭제되고, **취소**를 누르면 받은 팩스함으로 돌아갑니다.

## 회신

**회신**은 [팩스 보내기](send-fax.md) 화면을 열어 수신처에 발신 번호를 채워 줍니다. 주소록에 등록된 번호가 있으면 그 번호를 쓰고, 쓸 수 있는 번호가 없으면 수신처를 비워 둡니다. 받은 원본 팩스가 자동으로 첨부되어 함께 전송되며, 화면에 "원본 팩스를 함께 보냅니다."와 PDF 링크가 표시됩니다.
